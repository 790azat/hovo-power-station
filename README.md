# Hovo Power Station

Мобильное приложение (iOS + Android) и сервер для зарядной станции электромобилей: водитель находит станцию на карте или сканирует QR-код, выбирает разъём и сумму, платит через **Idram** или **привязанной банковской картой**, и зарядка включается сама.

```
app/      мобильное приложение (Expo / React Native, один код для iOS и Android)
server/   сервер: API для приложения, оплата Idram и картой, управление зарядками по OCPP 1.6
```

## Как это работает

1. Водитель открывает приложение и видит карту со станциями. Зелёная точка значит, что есть свободный разъём, оранжевая значит всё занято, серая значит станция не в сети. Нажатие на точку выбирает станцию. Ещё можно отсканировать QR-код на зарядке или ввести код вручную.
2. Выбирает разъём и сумму (1000 / 3000 / 5000 / 10000 ֏ или своя), приложение показывает, сколько это примерно кВт·ч.
3. Платит:
   * **Idram**: открывается страница Idram, после оплаты Idram сообщает серверу (`/idram/result`);
   * **картой**: карта привязывается один раз (списывается и сразу возвращается 10 ֏), дальше оплата в одно нажатие без ввода карты.
   * Если на балансе есть деньги, они используются в первую очередь.
4. Сервер отправляет зарядке `RemoteStartTransaction`, водитель вставляет кабель, зарядка идёт. В приложении видно кВт·ч, мощность, время и сумму.
5. Зарядка останавливается кнопкой в приложении, на станции или сама, когда оплаченная сумма израсходована. **Неизрасходованный остаток возвращается на баланс** в приложении и тратится при следующей зарядке.
6. Если кабель не вставили за 3 минуты, зарядка отменяется и деньги возвращаются на баланс.

Языки приложения: армянский (по умолчанию), русский, английский.

## Запуск для проверки (без настоящей зарядки и без настоящих платежей)

Нужен Node.js 22.18 или новее.

```bash
# 1. сервер (Idram и карты в тестовом режиме)
cd server
npm install
npm start

# 2. в другом окне: виртуальная зарядка, которая ведёт себя как настоящая по OCPP
cd server
npm run simulator

# 3. приложение
cd app
npm install
EXPO_PUBLIC_API_URL=http://<IP-вашего-компьютера>:8080 npx expo start
```

Отсканируйте QR из терминала приложением **Expo Go** на телефоне. Код тестовой станции: `HOVO-001`.

Автотесты сервера (оплата Idram, проверка подписи Idram, привязка и оплата картой, старт/стоп, возврат остатка): `cd server && npm test`.

## Деплой на свой VPS (Ubuntu 22.04/24.04)

На сервере под root выполните одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/790azat/hovo-power-station/main/deploy/install.sh | bash
```

Скрипт ставит Node.js и Caddy (https), запускает сервер как службу `hovo` и сам раздаёт веб-версию приложения (PWA). В конце он печатает:
* адрес приложения: `https://<ip>.sslip.io` (или ваш домен, если задать `DOMAIN=...` перед командой);
* адрес OCPP для зарядок: `wss://<адрес>/ocpp/HOVO-001`.

Настройки лежат в `/etc/hovo.env` (ключи Idram и банка; `IDRAM_MOCK=0`, `CARD_MOCK=0` включают настоящие платежи), после изменения выполните `systemctl restart hovo`. Обновление делается той же командой. Веб-сборка для сервера берётся из ветки `web-live` (`cd app && npm run build:live`).

## Подключение зарядной станции Tellus Power (60 кВт DC)

Станция поддерживает OCPP, и сервер работает с ней по OCPP 1.6J. В сервисном меню станции (или через установщика Tellus) укажите:

- **Адрес центральной системы (Central System / OCPP URL):** `wss://<ваш-домен>/ocpp/` и **ID станции (Charge Point ID):** `HOVO-001`. Если поле одно, полный адрес такой: `wss://<ваш-домен>/ocpp/HOVO-001`.
- **Версия протокола:** OCPP 1.6J (JSON).
- **Связь:** Ethernet, 4G или Wi-Fi, главное чтобы был интернет.
- **Оплата на самой станции (iPos, наличные)** работает отдельно от приложения, её трогать не нужно.

Типы разъёмов по умолчанию: оба CCS2 по 60 кВт. Если второй разъём другой (GB/T или CHAdeMO), поменяйте на сервере:

```
cd /opt/hovo/src/server && node --env-file=/etc/hovo.env src/admin.ts plug --id HOVO-001 --connector 2 --type "GB/T"
```

## Что нужно для запуска по-настоящему

| Что | Где взять | Куда вписать |
|---|---|---|
| Договор с Idram: номер счёта и секретный ключ | Idram, раздел для бизнеса | `IDRAM_REC_ACCOUNT`, `IDRAM_SECRET_KEY`, `IDRAM_MOCK=0` |
| В кабинете Idram указать адреса | | Result URL: `https://<сервер>/idram/result`, Success: `/idram/success`, Fail: `/idram/fail` |
| Эквайринг карт (ArCa iPay через банк: Ardshinbank, Inecobank, ACBA, Converse и др.) с разрешением на привязку карт | ваш банк | `CARD_GATEWAY_USERNAME`, `CARD_GATEWAY_PASSWORD`, `CARD_MOCK=0` |
| Сервер с https | любой VPS или хостинг для Node.js | `PUBLIC_URL` |
| Зарядки с OCPP 1.6J | в настройках зарядки указать адрес | `wss://<сервер>/ocpp/<ID станции>` |
| Google Maps ключ для Android | Google Cloud Console | `GOOGLE_MAPS_ANDROID_KEY` при сборке |
| Аккаунты Apple Developer и Google Play | | сборка через `npx eas-cli build` |

Все настройки сервера описаны в [`server/.env.example`](server/.env.example).

### Добавить станцию

ID станции должен совпадать с ID, который зарядка использует в адресе OCPP.

```bash
cd server
npm run admin -- add --id HOVO-002 --name "Hovo Gyumri" --address "Гюмри, ..." --lat 40.79 --lng 43.84 --price 120 --connectors 2
npm run admin -- set --id HOVO-001 --lat 40.18 --lng 44.51   # поменять координаты/цену
npm run admin -- list
```

### QR-код на станции

На каждый разъём наклеивается QR с текстом `hovo://station/<ID станции>?connector=<номер>`, например `hovo://station/HOVO-001?connector=1`. Можно сделать в любом генераторе QR.
